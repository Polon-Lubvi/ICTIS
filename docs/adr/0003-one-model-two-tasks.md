# ADR 0003. Одна модель для суммаризации и тональности

**Статус:** принято

## Контекст
Системе медиамониторинга нужны две функции: краткое изложение новости и её тональность по отношению к бренду.

## Решение
Одна модель с одним адаптером LoRA решает обе задачи. Задача задаётся инструкцией в запросе («Кратко изложи новость» или «Определи тональность»).

## Рассмотренные альтернативы
| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| Одна модель на две задачи | Одно обучение, одна модель в памяти, проще демо | Задачи могут мешать друг другу |
| Две отдельные модели | Каждая настроена под свою задачу | Вдвое больше обучения и памяти |
| LLM для резюме + отдельный BERT-классификатор тональности | Быстрый и точный классификатор | Два разных стека; BERT остаётся базовым методом для сравнения |

## Последствия
- Качество тональности сравнивается с TF-IDF и готовым BERT-классификатором.
- Если одна задача заметно ухудшит другую, это фиксируется в выводах как ограничение.
