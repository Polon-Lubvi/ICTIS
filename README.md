# Анализ новостного контента: суммаризация и тональность на LoRA

Система делает краткое изложение новостей и определяет их тональность для медиамониторинга брендов. Малая открытая языковая модель дообучается методом LoRA на корпусе новостей Gazeta.

## Запуск

1. Открыть `01_pipeline.ipynb` в Google Colab.
2. Среда выполнения → Сменить среду выполнения → T4 GPU.
3. Секреты (значок ключа слева) → добавить `HF_TOKEN` (токен Hugging Face, тип Read) → включить доступ из блокнота.
4. Среда выполнения → Выполнить все.
5. Разрешить доступ к Google Drive.

Других ручных действий не требуется.

## Данные и результаты

Всё хранится на Google Drive в папке `MyDrive/tabd26`:

| Папка | Содержимое |
| --- | --- |
| `data/raw` | Исходный корпус Gazeta (parquet), не изменяется |
| `data/processed` | Подготовленные выборки |
| `checkpoints` | Чекпойнты и адаптеры LoRA |
| `mlruns` | Эксперименты MLflow |
| `reports` | Отчёт о качестве, проверка утечки, журнал прогона, метрики, графики |

Повторный запуск не скачивает данные и не обучает модели заново, если результат уже есть на Drive.

Длительность прогона на T4 (примерно): загрузка и проверка данных — 10–15 мин; обучение одной конфигурации LoRA — 2–4 ч.
