# ADR 0002. LoRA вместо полного дообучения

**Статус:** принято

## Контекст
Полное дообучение меняет все параметры модели и требует памяти на веса, градиенты и состояние оптимизатора. Для модели 1,5 млрд параметров это больше 16 ГБ памяти T4.

## Решение
Дообучаем методом LoRA: исходные веса заморожены, обучаются только небольшие матрицы-адаптеры. Основной вариант — QLoRA (модель загружена в 4 битах).

## Рассмотренные альтернативы
| Вариант | Память | Обучаемые параметры | Итог |
| --- | --- | --- | --- |
| Полное дообучение | Не помещается в T4 | 100 % | Отклонено |
| LoRA, модель в fp16 | Помещается | Меньше 1 % | Сравнивается в экспериментах |
| QLoRA, модель в 4 битах | Меньше всего | Меньше 1 % | Основной вариант |
| Только промпт, без дообучения (zero-shot) | Минимум | 0 | Используется как базовый метод |

## Последствия
- Адаптер весит десятки мегабайт, его легко сохранять на Drive после обрыва сессии.
- 4-битная загрузка может немного снизить качество, это проверяется сравнением LoRA и QLoRA.
